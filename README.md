## 📖 프로젝트 개요

**ONE HIT OUT**은 기획부터 출시까지 전 과정을 단독으로 진행한 2인 협동 서바이벌 게임입니다.
한 번이라도 맞으면 즉사하는 규칙 속에서 최대한 오래 살아남는 것이 목표이며, Steam 앞서해보기로 출시했습니다.

- **개발 인원** : 1인 개발
- **개발 기간** : 2025.07 ~ (계속 업데이트 중)
- **출시 상태** : Steam 앞서해보기(Early Access) 출시
